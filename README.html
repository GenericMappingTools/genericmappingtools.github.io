Source for the GMT website¶

This repository contains the sphinx source files for building the GMT website.

Compiling the site¶

Run:

make

Pushing changes to GenericMappingTools/website triggers a GitHub Actions workflow. When changes are pushed to the master branch (directly or by merging a Pull Request), Github Actions will push the compiled site to the GenericMappingTools/genericmappingtools.github.io repository. Github serves this repository under http://genericmappingtools.github.io.
